# 鸣潮自动战斗

Windows 下的独立桌面工具。通过截图识别游戏 HUD、角色和敌人，再用 Windows 键鼠接口执行战斗。使用 C# 和系统组件实现战斗，不依赖参考项目的框架。

换电脑继续开发时，参见 [开发交接](README-HANDOFF.md)。

## 使用

1. 打开 `TideCombat.exe`，选择游戏来源，进入可战斗场景。推荐 1920×1080 无边框窗口和默认 HUD。
2. 首次可点「仅检测」，切到游戏并用鼠标中键锁定敌人。回到工具查看识别结果，再点「停止」。
3. 按 **Ctrl + Alt + F8** 开始或停止，也可以用工具窗口里的按钮。角色倒下后工具会自动点击复活按钮，可在战斗设置中关闭。

若本地客户端以管理员身份运行，工具会在启动战斗时检测权限差异。点击确认并通过 Windows 授权后，工具会以管理员身份重启并恢复战斗待命。仅检测模式仍可在普通权限下启动。

### 游戏来源

- 「本地客户端 · 前台」使用屏幕画面和系统键鼠输入。切出游戏时暂停。
- 「本地客户端 · 后台」按客户端窗口读取画面并投递窗口消息。优先使用 Windows 图形捕获，也可读取支持 `PrintWindow` 的窗口。要持续获得画面，请保持客户端窗口打开。
- 「网页云游戏 · 前台」使用 Edge、Chrome 或 Chromium 的全屏串流画面。点击「打开官网云游戏」，由玩家登录并全屏进入游戏。识别使用适配视频压缩的血条阈值，并在战斗中允许血条短暂消失。
- 「网页云游戏 · 后台」点「打开官网云游戏」创建一个专用的 Edge 或 Chrome 窗口。完成登录并进入游戏后即可切到其他应用。专用浏览器使用独立配置，工具通过回环地址读取串流画面并发送按键。

默认在检测到敌人血条时尝试锁定，锁定确认后普攻，并按技能就绪状态释放共鸣技能、声骸和共鸣解放。关闭「自动锁定」后，可自己用中键确定攻击目标。

### 逐角色连招

内置参考版本注册的 58 个角色。按画面识别角色和当前状态，执行各自的变奏入场、重击／长按、技能顺序、第二阶段、队友联动与换人时机。漂泊者可按属性识别并执行衍射、湮灭、气动或导电连招。在「角色变体」中设置尤诺六链、洛可可六链、千咲主输出及 Suoming 主输出。

- 槽位默认「自动识别」。画面中的头像或属性无法确认时，可在该槽位直接选择角色和漂泊者属性。
- 「通用定位」及「通用驻场」用于未识别出的角色。可在「角色档案」录入新头像并配置通用轮转。
- 默认在确认开战和结束时切到治疗。可关闭这项设置，也可只保留低血量时切治疗。已识别角色按专用连招规则决定何时切人。
- 发现处决提示时，按角色连招时机交替发送互动和普攻。判断椿的长按进度时读取画面里的回路，在进度停滞后松开重试。

- 技能栏从左到右按共鸣技能、声骸、共鸣解放读取。默认识别游戏画面上的绑定，用于处理 Q、R 位置上的实际绑定变化。游戏中改过技能键时，可关闭自动识别并填写实际的三个按键。切人键使用数字行 `1`、`2`、`3`，锁敌使用鼠标中键。
- 启动战斗、开始检测或保存角色档案时，设置写入程序同目录的 `CombatSettings.json`。角色档案保存由用户画面计算的头像特征。

### 批量强化声骸

「强化声骸」按钮会打开强化条件对话框：必须有双爆、双爆前全有效、双爆总计/首条阈值、满级有效词条数、第一条必须有效、有效词条多选、成功后暂停。

使用前请在背包声骸界面筛选目标声骸、按等级从 0 排序，并在游戏强化设置里开启「阶段放入」和「同时调谐」。任务会逐个强化、读取词条、按规则继续强化/弃置/锁定。详见 [docs/ENHANCE.md](docs/ENHANCE.md)。

### 梦魇巢穴

任务下拉框选择「梦魇巢穴」：勾选声骸巢穴/梦魇净化，工具会扫描 F2 图鉴中所有未完成（0/24、0/36、0/48、0/41）的巢穴，逐个传送、战斗、拾取；死亡 3 次或传送失败的目标本轮跳过。详见 [docs/NIGHTMARE.md](docs/NIGHTMARE.md)。

### 体力本

任务下拉框可选择「无音区」「材料本」「模拟领域」：自动读取体力、F2 传送进本、战斗、领奖、按体力选择单倍/双倍并循环，体力耗尽或连续死亡 3 次后停止。详见 [docs/DOMAIN.md](docs/DOMAIN.md)。

### 刷 4C 声骸

「刷4C声骸」按钮会打开参数对话框：传送方式（不使用 / Boss 挑战 / 周常挑战 / 特异梦魇）、Boss 序号、挑战等级、刷取次数、开打前等待、Boss 档案和拾取方式（直走 / 绕圈 / YOLO）。传送使用 F2 图鉴；大世界无标记时用小地图箭头朝向寻路，也可用 M 地图标记传送。拾取用内置 YOLOv8 声骸模型，等级与「吸收」文字用内置 PP-OCRv6 识别（均通过 ONNX Runtime，随包提供）；看到地面声骸会立即结束战斗并寻路拾取，角色倒下会自动点击复活。

需要前台窗口（本地客户端·前台或网页云游戏·前台），后台模式不支持菜单点击。完整流程、与参考实现的逐项差异见 [docs/FARM4C.md](docs/FARM4C.md)。

## 构建和验证

需要 64 位 Windows 10 或 11 及系统自带的 .NET Framework 4.8。使用打包好的程序无需安装其他依赖。解压源码后，在 PowerShell 中运行下面两条命令。

```powershell
.\build.ps1 -Test
.\bin\TideCombat.exe
```

`src/` 包含窗口捕获、HUD 识别、角色连招状态机、换人决策和桌面界面。内置头像和动作提示识别使用 `data/Signatures.tsv` 中的数值特征，编译和运行只读取这些特征。可用 `-ReferenceDirectory` 启用离线截图回放。配合 `-RebuildSignatures` 可从本地参考截图重新提取特征。

### 参考源码和行为校对

校对使用 `ok-wuthering-waves-master` 的本地源码快照。该快照的 `config.py` 标为 `dev`，中文更新日志首项为 `v3.8.4`。`AutoCombatTask.py`、`CombatCheck.py` 和 `BaseCombatTask.py` 的 SHA-256 前缀分别为 `5A2745060107`、`94AD744B908E`、`55E9E4977ACD`。

离线校对覆盖角色注册与基础定位、副 C 变奏联动、协奏临满重判、换人前后处决、战中重锁和若干具体连招。识别器使用独立的图像特征，角色技能动画和复杂编队分支仍可能有时序差异。「低血量时优先切治疗」是本工具附加选项，需要按参考原版换人时可关闭。

离线套件包含 58 个角色与漂泊者四种形态的状态机运行、典型连招分支、背景窗口捕获的合成窗口，以及 720p 至 4K 常见 16:9 分辨率的 HUD 和角色画面回放。进入挑战和选择编队由玩家完成。离线测试使用模拟 HUD 和现有截图，实际客户端或串流的采集与键鼠交互需在相应运行环境中验证。

本机安装 Edge 或 Chrome 时，可用本地 HTML 额外检查浏览器截图和按键通道。此测试启动无界面的临时浏览器，不访问游戏官网。

```powershell
.\bin\TideCombat.Tests.exe --browser-fixture .\tests\cloud-fixture.html
```
