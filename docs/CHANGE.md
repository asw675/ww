# 批量改主属性（Change Echo）

对应 ok-ww `ChangeEchoTask`：对背包里筛选好的 0 级声骸逐个改主属性（数据重构）。

## 前提

- 游戏语言为**简体中文**（属性/按钮依赖中文 OCR）。
- 打开背包 → 声骸页，筛选目标声骸，按等级从 0 排序。
- 目标属性不能与当前主属性相同（否则任务报错停止，需要改筛选）。
- 可在本地客户端、网页云游戏前台或已打开的专用后台云游戏中使用。专用后台支持本任务所需的画面识别、菜单点击及 ESC；请手动登录并确认背包筛选后再运行。任务锁定启动时的专用会话与画面尺寸，发生断线、文档导航或视口变化时停止；不执行自动登录、额外月卡操作或系统键鼠回退。CLI `-e` 在这种来源下只退出工具，不尝试关闭其他窗口。

## 配置

目标属性：攻击 / 暴击伤害 / 暴击 / 生命 / 防御 / 共鸣效率 / 冷凝 / 热熔 / 导电 / 气动 / 衍射 / 湮灭伤害加成。

## 流程

1. OCR 右下角「培养」按钮；找不到则提示先在背包筛选排序。
2. 两次核对当前声骸明确数字等级 `+0`～`+25`，避免仅凭「声骸技能」标题误判零级。确认非零级才正常结束，数字持续未知或冲突时报告失败。
3. 点「培养」直到界面切换；等待「声骸强化」。
4. OCR 当前主属性（0.09–0.15, 0.20–0.26），与目标相同则报错。
5. 点 (0.04,0.41) 打开主音属性 → 等「主音属性」→ 点 (0.52,0.71) → OCR 找到目标属性并点击。
6. 点「确认」→ 点「数据重构」→ 等「获得声骸」。
7. 确认获得声骸后保存结果截图，按原版1秒间隔 ESC 返回「培养」页面，再计入成功数量并继续下一个；返回异常但已确认获得声骸时仍计入真实结果。正常结束且已有成功记录时打开截图目录。

## OCR 文本纠正

参考实现带文本纠错，本项目同样处理：
`凝夜自霜→凝夜白霜`、`主属性灭伤害加成→主属性湮灭伤害加成`、`主属性行射伤害加成→主属性衍射伤害加成`、`灭伤害加成→主属性湮灭伤害加成`（按最长匹配优先）。

## 与 ok-ww 的差异

| 项 | 参考 | 本项目 |
|---|---|---|
| 起点 | 背包声骸界面 | 相同（不按 B，由用户先打开） |
| 判定流程 | OCR + 坐标 | 相同 |
| 文本纠错 | `add_text_fix` | 独立实现，最长匹配优先 |
| 失败截图/打开目录 | 有，成功数 ≥ 1 后自动打开目录 | 成功/失败保存截图，有成功记录时正常结束自动打开目录 |

## 已知限制

1. 未实机校准；OCR 全屏等待较慢（每次约 1 秒）。
2. 截图保存到 `screenshots/success|failed`；持续保留既有记录。
3. 目标属性与当前完整属性名相同时直接停止；暴击与暴击伤害分别判定。
4. 专用后台云游戏的菜单输入和完整流程仍需在 Windows 实机验证，不代表其他一次性任务已支持该来源。
