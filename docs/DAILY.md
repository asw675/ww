# 一条龙

在任务下拉框选择「一条龙」并点「运行任务」。勾选要执行的项目，选中一行后用「上移」「下移」调顺序。程序从上到下执行已勾选的项目。「仅保存」保存计划并返回主窗口，「保存并开始」会保存后运行。多账号日常也使用这个计划。

| 任务 | 说明 |
|---|---|
| 梦魇巢穴 | 可按日常需求补一只、直接刷取一只，或清理全部。按需补捡时日常积分已满就跳过，计划中已选刷无音区也会跳过。 |
| 刷体力本 | 日常积分未满且当日已用波片少于 180 时，按所选副本刷取。180 是启动目标，双倍领取或培养材料可能使实际消耗超过剩余目标。已确认活跃度页面时，翻页后仍缺失的消耗计数或未读到的积分按 0 处理。无音区和材料本可指定 F2 列表序号，模拟领域可指定材料。 |
| 领取日常奖励 | 确认索拉指南的活跃度页面，核验领取按钮和领取后状态。 |
| 领取邮件 | 识别终端信封和邮件标题，点击「全部领取」后核对领取回执或「全部邮件的附件已经领取完毕」提示。 |
| 领取战令 | 默认按 HUD 入口打开「先约电台」，必要时从已确认终端恢复；分别核对电台任务和等级奖励。明确确认本期未开放或已结束才跳过，输入失败或无法核验不算领取成功。 |
| 周常乐园 | 检查进度，按需运行乐园。 |
| 合并弃置声骸 | 检查弃置声骸并按条件合并。 |
| 刷 4C 声骸 | 使用刷 4C 的配置，须先在刷 4C 设置里开启自动传送。 |
| 处理月卡弹窗 | 仅处理已识别的月卡弹窗，并确认回到大世界。 |

隐式默认计划按 OKWW v3.8.4 顺序：以一次已核验的初始日常进度决定是否处理梦魇巢穴、是否刷体力，再领取日常、邮件和战令奖励，最后执行附加项目。条件不满足的前置步骤不进入任务流程。不能确定页面或数值冲突时，不盲目消耗体力。WW 的培养目标、单次捕获、月卡显式步骤及自定义勾选/换序为额外模式：培养目标保留体力优先、避免重复梦魇的顺序；自定义计划保留所选项目及顺序。只选「领取邮件」时会直接运行邮件步骤。体力本结束后会记录实际消耗。

运行日志会区分未勾选、已勾选但未执行、已核验、跳过和失败项目。参考默认模式仅保留失败证据，不额外在成功步骤前后同步截图；WW 扩展计划的起止图和关键界面保存在实际日志目录的 `evidence` 子目录，默认保留最近 10 次运行。整图色差用于帮助定位画面变化，完成情况根据游戏中的回执、控制状态、资源读数或目标轮数判定。默认模式与原版一样只在梦魇、周常乐园和合并弃置声骸的非关键异常后尝试恢复继续，其余真实失败停止；已恢复的失败仍明确保留在最终日志。遇到报错时，可在主窗口右下角点「打开日志目录」查看当次记录。

## 命令行启动

先在窗口里保存一条龙计划并打开游戏。在 PowerShell 中进入 `TideCombat.exe` 所在目录后运行以下命令。

```powershell
.\TideCombat.exe -t DailyTask -e
```

`-t` 或 `--task` 加载指定任务，默认保持 OKWW v3.8.4 的任务列表编号；也支持注册名称及完整类名，例如 `-t 1` 与 `-t DailyTask`、`-t src.task.DailyTask.DailyTask` 等价。工具识别到游戏窗口后执行当前配置。参数错误记入日志，并以状态码 2 退出。

| 编号 | 注册名称 | 任务 |
|---|---|---|
| 1 | `DailyTask` | 一条龙 |
| 2 | `FarmEchoTask` | 刷 4C |
| 3 | `NightmareNestTask` | 梦魇巢穴 |
| 4 | `TacetTask` | 无音区 |
| 5 | `ForgeryTask` | 材料本 |
| 6 | `SimulationTask` | 模拟领域 |
| 7 | `MultiAccountDailyTask` | 多账号日常 |
| 8 | `MultiAccountConfigTask` | 多账号配置 |
| 9 | `MergeEchoTask` | 合并弃置声骸 |
| 10 | `EnhanceEchoTask` | 批量强化 |
| 11 | `ChangeEchoTask` | 改主属性 |
| 12 | `GardenTask` | 周常乐园 |

第二索拉和拉海洛方块采用 v3.8.14 的注册名称。建议计划任务始终使用名称而非编号：

```powershell
.\TideCombat.exe -t GalGameTask
.\TideCombat.exe -t RahaiBlocksTask
```

已有 v3.8.14 数字命令可显式指定 `--task-version=3.8.14`（例如 `-t 2 --task-version=3.8.14` 为第二索拉，`-t 3 --task-version=3.8.14` 为拉海洛；完整顺序为 Daily、GalGame、RahaiBlocks、FarmEcho、NightmareNest、Tacet、Forgery、Simulation、Cultivation、MultiAccountDaily、MultiAccountConfig、MergeEcho、EnhanceEcho、ChangeEcho、Garden）。不传该参数的旧编号含义不变，`-t 2` 仍是刷4C。手动打开对应活动页面后再运行；拉海洛仅本地客户端自动/前台，专用后台云不会接管活动任务。

`-e` 或 `--exit` 在本次任务成功后关闭游戏和工具。省略时沿用已保存的退出设置。任务失败或取消后会保留窗口以便查看结果。
