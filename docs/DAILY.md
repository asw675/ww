# 一条龙（Daily Task）

对应 ok-ww `DailyTask`：读取日常进度 → 按需补梦魇/刷体力 → 领日常/邮件/战令 → 可选附加任务。

## 配置

| 项 | 说明 |
|---|---|
| 刷取目标 | 无音区 / 材料本 / 模拟领域 |
| 无音区序号 / 材料本序号 | F2 列表序号（1 起） |
| 模拟领域材料 | 共鸣者经验 / 武器经验 / 贝币 |
| 刷梦魇巢穴补日常声骸 | 缺日常时刷 1 个声骸（捕获模式） |
| 自动全刷梦魇巢穴 | 无条件跑完整梦魇巢穴任务 |
| 检查并执行周常乐园 | 积分未满则跑乐园 |
| 弃置声骸超过 1000 时合并 | 跑合并任务（失败不阻断） |
| 结束后刷 4C 声骸 | 需要 4C 设置里已开启传送 |

## 流程

1. 回到大世界；F2 任务图鉴 → 读取 `N/180` 进度（首页找不到则翻页再读）与日常积分。
2. `积分 >= 100` 视为已领日常；体力预算 = 180 - 已用。
3. 需要梦魇时：
   - 勾选「自动全刷」→ 完整梦魇巢穴；
   - 否则「补日常声骸」→ 捕获模式（拾取到第一个声骸即停）。
4. 需要体力时：按目标刷副本，最多消耗到 180 点（`DomainOptions.MaxStamina`）。
5. 领日常奖励（任务页 → 领取）、邮件、战令。
6. 附加任务：乐园 → 合并 → 4C。

## 与 ok-ww 的对照

| 项 | 参考 | 本项目 |
|---|---|---|
| 进度/积分 OCR | 相同区域与正则 | 相同 |
| 体力预算 | `must_use = 180 - used` | `MaxStamina` 预算，达到即停 |
| 梦魇捕获模式 | 负片模板判断是否捕获 | 拾取到第一个声骸即停（近似） |
| 领日常/邮件/战令 | 坐标 + OCR | 相同 |
| 附加任务 | 任务调度 | 顺序调用各 Runner |

实现为 `DailyRunner` 编排，复用 `DomainRunner`/`NightmareNestRunner`/`GardenRunner`/`MergeRunner`/`FarmLoop`。

## 已知限制

1. 捕获模式用「首次拾取成功」代替参考的图标负片判定，可能提前/延后停止。
2. 战令 OCR/坐标未实机校准。
3. 未实现参考的 `Exit After Task`（完成后退出游戏/程序）。
4. 合并任务失败只记录、不中断（与参考 `notify_if_not_enough=False` 一致）。
