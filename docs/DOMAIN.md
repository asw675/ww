# 体力本（无音区 / 材料本 / 模拟领域）

对应 ok-ww 的 `TacetTask`、`ForgeryTask`、`SimulationTask`（后两者共用 `DomainTask`）。三个任务共用同一套「读体力 → 传送进本 → 战斗 → 领奖 → 消耗体力 → 继续/退出」循环，差异只在传送目标。

## 使用前提

- 支持本地客户端的自动、后台和前台模式，以及网页云游戏前台。
- 已在 F2 图鉴解锁对应副本。
- HUD 默认布局；体力数字需清晰可读（OCR 读取）。

## 配置

| 项 | 说明 |
|---|---|
| 副本类型 | 无音区 / 材料本 / 模拟领域 |
| 序号 | F2 列表中的序号（1 起；无音区 21 项、材料本 20 项） |
| 模拟领域材料 | 共鸣者经验 / 武器经验 / 贝币（仅模拟领域） |

## 流程

1. 识别当前画面。终端使用索拉指南图标，图鉴已打开时直接使用当前页面。
2. 在大世界使用图鉴快捷键，仍停留在大世界时用 Alt 点击指南入口，确认左侧「Boss 图鉴」已选中。
3. 读取顶部当前波片、上限和备用波片，再选择对应的副本分类。
4. 体力不足一次所需（无音区 60、材料本/模拟领域 40）→ 结束。
5. 在列表中定位目标行（不可见时按滚动条公式补滚）→ 点击 → 传送 → 开始挑战 → 处理「不再提醒」。
6. 无音区直接寻敌开战。材料本和模拟领域先前进交互，再战斗和领取奖励。
7. 当前体力足够双倍时选择双倍。日常剩余目标超过单次消耗且当前与备用合计足够双倍时，也选择双倍。目标是继续使用备用体力的条件，实际消耗可能超过日常剩余值。需要补充时会确认游戏中当前选中的方式，包括备用波片、结晶溶剂和星声。补充后重新读取余额，再次领取，并核对扣减或奖励回执。
8. 可继续则点「再次挑战」，否则退出副本回大世界。
9. 副本内死亡：退出副本回大世界，重新从 F2 进本；累计 3 次恢复失败则停止。
10. 连续 3 次战斗后找不到领奖界面 → 停止并报失败；等待开战超时按恢复计数，不会无限循环。

## 与 ok-ww 的对照

| 能力 | 参考 | 本项目 |
|---|---|---|
| 体力读取 | `N/M` 取 N 为当前，单独数字为备用，上限 M 不计入 | `DomainMath.ParseStamina`：同样只取 N，斜杠右侧视为上限 |
| 单倍/双倍判定 | 当前体力 ≥ 两倍，或 daily 剩余 > 一次且总量 ≥ 两倍 | 相同判定 |
| 列表定位 | 滚动条顶部 + 行高公式 + 按已跨分组补页眉 + 自适应补滚 | `DomainMath.ScrollOffset` 按 structure 计算跨越分组；定位失败再补滚一次 |
| 死亡恢复 | 关闭弹窗→退本→回血→重进，最多 3 次 | 退本后 M 地图找 `map_way_point` 传送回血，再重进；最多 3 次 |
| 挑战按钮/跳过确认 | 模板 | 同签名 + 确认弹窗 |
| 战斗 | `combat_once` | 复用 `BattlePlanner` |

实现方式：先读参考源码整理行为规格，再用同步 `WorldSession`（截图/OCR/点击/等待）+ `DomainRunner` 重新实现，不是逐行翻译。

## 已知限制

1. 未在真实客户端校准坐标与 OCR 区域。
0. 失败会通过 `DomainRunner.Failed` 向上传递，不再静默返回。
2. 模拟领域的材料行使用参考坐标（0.898, 0.533 + index*0.14），列表改版会失效。
3. 无音区结算按钮使用 0.365/0.640 坐标，其余副本用 0.42/0.68；未实机验证。
4. 已记录回信标状态：首次死亡后传送回血，后续死亡不再重复传送。
4. 体力 OCR 失败会直接报错停止（参考会截图后返回 -1）。
