# 批量强化声骸（Enhance Echo）

批量处理背包中已筛选的 0 级声骸。每档调谐后读取副词条，按 okww 的规则继续强化、弃置或锁定。

## 使用前提

1. 游戏与工具语言为**简体或繁体中文**（词条依赖中文 OCR）。
2. 打开背包 → 声骸页，设置筛选条件。
3. 排序选**等级顺序**。程序需要重置列表时会把它恢复到升序。
4. 强化设置中开启**阶段放入**与**同时调谐**。每档投入和强化等级由游戏的阶段放入设置决定。

## 参数

强化设置支持仅保存、开始强化和恢复默认。仅保存不会启动游戏任务。选项旁的提示说明判定条件。

| 项 | 对应 ok-ww | 说明 |
|---|---|---|
| 必须有双爆 | 必须有双爆 | 最终必须同时有暴击与暴击伤害 |
| 双爆前必须全有效 | 双爆出现之前必须全有效词条 | 两种暴击属性均选为有效时，第一条暴击或暴伤之前的词条必须有效 |
| 双爆总计 >= | 双爆总计>= | 暴击 + 爆伤/2 |
| 首条双爆 >= | 首条双爆>= | 只检查第一条暴击（爆伤按一半） |
| 满级有效词条 >= | 有效词条>= | 已有有效词条 + 剩余孔位需达到的数量 |
| 第一条必须有效 | 第一条必须为有效词条 | 当前只有一条副词条且该词条无效时弃置 |
| 有效词条 | 有效词条 | 13 种副词条可多选，支持明确保存空列表 |
| 成功后暂停 | Pause after Success | 找到合格声骸后暂停任务 |

## 判定规则

与参考 `check_echo_stats` 一致：

1. OCR 将繁体和全角数值统一后，按同一行配对词条与数值。确认词条数量已达到本档开放的孔位后，用当前画面读到的词条判定。
2. `双爆前必须全有效`：在遇到第一条暴击/爆伤前，任何不在有效列表的词条直接判失败。
3. 首条**有效暴击类型**（在有效词条列表中的第一个暴击/爆伤）不满足阈值 → 失败。仅选一种暴击属性时与参考一致。
4. 剩余孔位不足以凑齐缺失的暴击/爆伤 → 失败。
5. 已同时有双爆时，`暴击 + 爆伤/2` 低于阈值 → 失败。
6. 只有 1 条词条且首条无效 → 失败。
7. `有效词条数 + 剩余孔位` 低于阈值 → 失败。
8. 通过且已有 5 条时锁定。通过且不足 5 条时继续强化。条件失败时弃置。

## 流程

1. 从已筛选的背包第一格开始，确认选中框后读取右侧实际等级。数字漏读时，在原版区域查找「声骸技能」标题作为零级判断的补充依据。首次未确认 +0 时重新定位列表，核对等级排序箭头后再选首格。只有升序下选中的首格连续两次读到相同的非零等级时才报告本批结束。选中、等级或排序无法确认时，提示具体原因。
2. 优先用窗口消息点「培养」，确认进入强化页。等待后连续两次仍识别到背包时补点一次，本地前台用系统鼠标补点。每档根据「清除」和「强化并调谐」等画面确认材料预选。前台和后台都优先用窗口消息点击「阶段放入」和「强化并调谐」。持续显示空预选时可补点一次，前台补点改用系统鼠标。右侧调谐器库存和本档经验材料投入分别显示。
3. 等待游戏响应。若连续识别到同一声骸、等级和材料预览，且游戏尚未弹出确认，才重试一次。自动窗口模式会先尝试切到游戏前台。分别处理材料溢出和调谐结果。关闭调谐结果后等待画面更新，连续两次仍看到弹窗时最多补点一次。自动模式在后台补点前会尝试切到前台并重新识别弹窗。
4. 游戏仍显示旧等级与目标等级时继续等候结算。确认新增词条后记录档位并执行规则。读取完整词条数值时可去掉小数前的单个杂点或数值末尾的横线。遇到数值缺失或有歧义时重新识别。需要锁定或弃置时，先确认当前标记状态，再按 C 或 Z。识别不出状态时等待重新识别，超时后记录错误。
5. 已锁定或已弃置后记录结果。开启成功暂停时，通过主界面「继续」退回背包，再处理下一只。

## 截图和日志

每次运行写入独立的 `screenshots/enhance-日期-时间/`。其中保存候选截图、阶段放入后的预览、每档词条、成功锁定、失败弃置及可截图的异常状态。确认本批没有 +0 时也保存完整背包画面，日志记录选中状态、读到的等级和排序方向。独立运行有成功项且整批正常结束时，自动打开本次目录。

应用日志记录本次配置、输入投递结果、每档 OCR 原文、词条配对、判定原因和截图路径。截图写入失败也会记录错误。

运行界面显示当前声骸和档位、已锁定与已弃置数量，以及最近确认档位的副词条、数值、无效条数和判定原因。保存本批截图后可直接打开其目录。

多账号配置可为每个强化任务单独保存条件。登录到该账号后会提示筛选声骸并等待继续。成功暂停和单独运行使用相同的继续按钮。

参考截图覆盖背包、五条副词条和材料溢出弹窗。锁定和弃置的四种状态使用当前 okww 对应图标校验。若当前游戏布局无法识别标记，任务会停在该只声骸并记录原因。
