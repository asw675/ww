# 批量强化声骸（Enhance Echo）

复刻 ok-ww `EnhanceEchoTask`：对背包里筛选好的 0 级声骸逐个强化，按词条规则决定「继续强化 / 弃置 / 锁定」。

## 使用前提

1. 游戏与工具语言为**简体或繁体中文**（词条依赖中文 OCR）。
2. 打开背包 → 声骸页，设置筛选条件。
3. 排序按**等级从 0 开始**（参考实现按等级升序）。
4. 强化设置中开启**阶段放入**与**同时调谐**，否则任务会报错停止。

## 参数

| 项 | 对应 ok-ww | 说明 |
|---|---|---|
| 必须有双爆 | 必须有双爆 | 最终必须同时有暴击与暴击伤害 |
| 双爆前必须全有效 | 双爆出现之前必须全有效词条 | 第一条暴击/爆伤之前的词条必须在有效列表 |
| 双爆总计 >= | 双爆总计>= | 暴击 + 爆伤/2 |
| 首条双爆 >= | 首条双爆>= | 只检查第一条暴击（爆伤按一半） |
| 满级有效词条 >= | 有效词条>= | 已有有效词条 + 剩余孔位需达到的数量 |
| 第一条必须有效 | 第一条必须为有效词条 | 首条无效直接弃置 |
| 有效词条 | 有效词条 | 13 种副词条多选 |
| 成功后暂停 | Pause after Success | 找到合格声骸后暂停任务 |

## 判定规则

与参考 `check_echo_stats` 一致：

1. 每个词条按 Y 坐标就近配对数值，解析 `暴击/爆伤/攻击%/生命%/防御%/效率/普攻/重击/解放/技能`。
2. `双爆前必须全有效`：在遇到第一条暴击/爆伤前，任何不在有效列表的词条直接判失败。
3. 首条暴击/爆伤不满足阈值 → 失败。
4. 剩余孔位不足以凑齐缺失的暴击/爆伤 → 失败。
5. 已同时有双爆时，`暴击 + 爆伤/2` 低于阈值 → 失败。
6. 只有 1 条词条且首条无效 → 失败。
7. `有效词条数 + 剩余孔位` 低于阈值 → 失败。
8. 通过且已满 5 条 → 锁定（C）；通过但未满 → 继续强化；失败 → 弃置（Z）。

## 流程

```
等待背包(OCR 培养)
  → 选择第一格(0.13,0.21)，OCR 声骸技能确认 0 级
  → 点击培养 → 阶段放入 → 强化并调谐
  → 处理「不再提示 / 调谐成功 / 点击任意位置」
  → OCR 词条 → 规则判定
      ├ 失败：Z 弃置（直到 echo_dropped），ESC 回背包
      └ 通过：C 锁定（直到 echo_locked），按配置暂停或 ESC 回背包
```

- 找不到 0 级声骸：先点第一格，再切换排序两次后重试，仍失败则认为没有可强化声骸，任务结束。
- 截图：成功/失败会保存到 `screenshots/success|failed/`（失败文件名带原因）。

## 与 ok-ww 的差异

| 项 | ok-ww | 本项目 |
|---|---|---|
| 词条 OCR | PP-OCR | 同一套 PP-OCRv6（det+rec） |
| 弃置/锁定状态 | 模板匹配 | 同样的模板签名（带亮度校验） |
| 确认按钮 | 模板 + OCR | 弹窗用 OCR 文案定位 |
| 失败截图 | 保存并打开目录 | 保存，不自动打开目录 |
| 调试截图/暂停 | debug 截图 | 仅成功/失败截图 |
| 词条规则 | `check_echo_stats` | 逐条移植，含同样的理由文案 |

## 已知限制

1. 依赖中文 OCR；英文/日文客户端不可用（与参考一致）。
2. 数值解析按「最近 Y 配对」，词条与数值错行时会误配（与参考一致）。
3. 未在真实客户端校准坐标；区域取自参考比例（1600×900 基准）。
4. 「阶段放入」与「同时调谐」必须提前在游戏设置开启。
