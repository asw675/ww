# 周常乐园（Garden）

对应 ok-ww `GardenTask`：自动点周常乐园事件，直到本周 6000 积分拿满。

## 流程

1. 恢复大世界（复用登录/月卡/断线恢复流程）；F2 打开图鉴 → 「任务」页签（`gray_book_quest`）。
2. 识别周度游历页签和乐园入口，优先使用落在已识别控件内的原版相对坐标（周度页签 OCR 漏读时仅在已验证任务图鉴上使用原版相对坐标）。如有可领取奖励，按顺序确认最多两项领取结果；首进后按3秒、2秒的原版节奏领取，结算后按2秒、1秒。
3. 读取左下角的本周积分。当前积分达到 6000 才结束，例如 `6000/6000` 或界面显示已达到上限。
4. 点击已识别的入口进入乐园。
5. 主循环先核对奖励弹窗、奇缘异遇、结算和「下一日」的文字：
   - 奖励弹窗同时识别「跳过」「确认」「隐藏当前界面」。从有标题和完整卡面的选项中按金色、紫色优先选卡，优先级相同时选更靠近中央的卡片。确认时核对目标卡位的绿色选中框和已点亮的按钮。确认仍禁用且卡片组未变化时，允许一次重选，必要时点「跳过」；
   - 奇缘异遇只选择文字为「你对此不感兴趣」的一行，核实选中和确认按钮已启用后提交。选项还未出现在列表内时，最多滚动两次再读取；
   - `garden_start_game`：按参考顺序选第一个祝福（三连点）；
   - 操作后核对连续画面。通过棋盘的阶段、日期或新一组卡片识别奖励后的推进，也会核对新的事件或结算。
6. 同时出现重新挑战和返回控件以及乐园积分文字时，按结算处理：
   - 文本中 `6000` 恰好出现一次时点击重新挑战。
   - 其他情况返回周常页，核对本周积分并确认可领取的奖励。未确认积分达到上限时报告失败。

## 与 ok-ww 的对照

| 项 | 参考 | 本项目 |
|---|---|---|
| 积分判定 | OCR 匹配 `6000` | 读取当前积分，识别已到上限提示 |
| 按钮选择 | 优先级 + 最高置信度 | 先判断奖励弹窗和结算，用文字识别「下一日」，其余事件按签名分数选择 |
| 奖励弹窗 | 金/紫/兜底坐标 | 核实已选标记后确认。可选择金色或紫色候选，也可点击识别到的「跳过」 |
| 祝福选择 | 三个固定坐标 | 相同 |
| 结束判定 | OCR 文本中 `6000` 次数 | 结算选择使用出现次数，完成结果依据周常页积分和领奖 |

实现为独立 `GardenRunner`（会话层 + 事件循环），不是逐行翻译。

## 防挂机规则

- 画面保持在同一控件时最多重试一次。购买、奇缘异遇确认、确认或跳过声骸奖励只发送一次。仍未确认游戏推进时停止并保留截图。
- 45 秒内没有已确认的操作或结算时停止。

## 已知限制

1. 未实机校准；同屏多个非优先按钮时按签名分数选择。
2. 奖励卡必须同时核验到卡面和标题才能点选。
3. 周常完成仍以游戏周常页显示的积分和领奖状态核验。
