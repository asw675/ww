# 周常乐园（Garden）

对应 ok-ww `GardenTask`：自动点周常乐园事件，直到本周 6000 积分拿满。

## 流程

1. 恢复大世界（复用登录/月卡/断线恢复流程）；F2 打开图鉴 → 「任务」页签（`gray_book_quest`）。
2. 识别周度游历页签和乐园入口，优先使用落在已识别控件内的原版相对坐标（周度页签 OCR 漏读时仅在已验证任务图鉴上使用原版相对坐标）。如有可领取奖励，按顺序确认最多两项领取结果；首进后按3秒、2秒的原版节奏领取，结算后按2秒、1秒。
3. 读取左下角的本周积分。当前积分达到 6000 才结束，例如 `6000/6000` 或界面显示已达到上限。
4. 点击已识别的入口进入乐园。
5. 主循环：识别普通 `garden_*` 事件（两个依赖型确认模板除外，金/紫奖励参与普通扫描），按优先级处理：
   - `garden_get_skip`：先点金色/紫色奖励，再点灰色确认；
   - `garden_not_interested`：点最下方一个，再点确认；
   - `garden_start_game`：按参考顺序选第一个祝福（三连点）；
   - 其它按钮直接点击。
6. 没有任何按钮时：若同时出现 `a_garden_restart` 与 `a_garden_back`，截图区域 OCR；
   - 文本中 `6000` 恰好出现一次时点击重新挑战。
   - 其他情况返回周常页，核对本周积分并确认可领取的奖励。未确认积分达到上限时报告失败。

## 与 ok-ww 的对照

| 项 | 参考 | 本项目 |
|---|---|---|
| 积分判定 | OCR 匹配 `6000` | 读取当前积分，识别已到上限提示 |
| 按钮选择 | 优先级 + 最高置信度 | 优先级加分 + 签名最高分（`BestMatchScored`） |
| 奖励弹窗 | 金/紫/兜底坐标 | 相同 |
| 祝福选择 | 三个固定坐标 | 相同 |
| 结束判定 | OCR 文本中 `6000` 次数 | 结算选择使用出现次数，完成结果依据周常页积分和领奖 |

实现为独立 `GardenRunner`（会话层 + 事件循环），不是逐行翻译。

## 防挂机规则

- 45 秒内既没有识别到可点击事件、也没有识别到结束界面 → 任务失败停止，不会无限等待。

## 已知限制

1. 未实机校准；同屏多个非优先按钮时按签名分数选择。
2. `garden_get_gold/purple` 用大范围模板搜索，背景相似时可能误判。
3. 未实现每日次数/失败重试等额外保护（参考只按 6000 判定）。
