# 合并弃置声骸（Merge Echo）

对应 ok-ww `MergeEchoTask`：把背包里的弃置声骸按 100 个一批全部合成。

## 前提

- 至少 1000 个弃置声骸（否则打开背包后不会出现合成入口弹窗）。
- 前台窗口；16:9。

## 流程

1. 回到大世界，按 `B` 打开背包，等待队伍 HUD 消失（背包界面）。
2. 若出现弃置合成弹窗：点弹窗左侧按钮关闭 → 点 (0.034,0.293) 进入分解/合成 → 点 (0.580,0.911) 确认。
3. 打开合成页：依次点击 (0.602,0.124)、(0.520,0.904)、(0.041,0.918)、(0.826,0.840)、(0.717,0.204)、(0.041,0.918)。
4. 循环合成满批：
   - 点 (0.310,0.915) → 等待并点击 `echo_select_all`（全选）；
   - OCR 区域 (0.670,0.660–0.895,0.958)，匹配 `100/100`；
   - 不是满批 → 结束；
   - 是满批 → 点 (0.782,0.910) → 处理「不再提醒」确认 → 点 (0.496,0.972) → 下一批。
5. 全部合成后 ESC 回大世界。

## 与 ok-ww 的对照

| 项 | 参考 | 本项目 |
|---|---|---|
| 打开背包 | `Bag Key`（默认 b） | 固定 `B` |
| 弃置弹窗检测 | 取消按钮模板 | 同签名 |
| 满批判定 | OCR `100\s*/\s*100` | 同区域、同正则（加了数字边界） |
| 全选按钮 | `echo_select_all` 模板 | 同签名 |
| 确认/跳过弹窗 | 模板 | 同签名 |

独立实现：同步 `MergeRunner` + `WorldSession`，按行为重写。

## 已知限制

1. 背包键固定为 `B`，未做配置项（参考可从配置读取）。
2. 未实机校准坐标；OCR 区域取自参考比例。
3. 只处理满批；不足 100 的余量会留在背包（与参考一致）。
