# 梦魇巢穴（Nightmare Nest）

任务按 F2 图鉴处理残象聚落和梦魇聚落。普通刷取会核对每个聚落的击败进度，单次捕获以新的声骸获取通知为结束条件。

## 刷取范围

| 选项 | 对应图鉴页签 |
|---|---|
| 声骸巢穴 | Boss 图鉴 → 残响（canxiang，y=0.83），含滚动页 |
| 梦魇净化 | 梦魇（mengyan，y=0.86），含滚动页 |

两项可同时勾选；队列顺序：声骸巢穴 → 声骸巢穴滚动 → 梦魇净化 → 梦魇净化滚动。

## 判定逻辑

- OCR 扫描图鉴列表区域（0.35,0.25–1,0.96），匹配 `N/M`；
- 处理 `0 ≤ N < M` 且 `M ∈ {24,36,48,41}` 的目标，已部分击败的聚落也在范围内；
- 用计数和同一行完整可见的「前往」或「直接挑战」文字定位按钮中心；
- 能读出残象聚落或梦魇聚落名称时跨滚动位置按名称去重。其他目标沿用页签、分母和行槽位；
- 清理全部时，重新读取同一聚落的 `M/M` 进度后计入完成。部分进度会优先重进原聚落，复查后仍无进度则报告失败。无法进入或传送未到达的目标会记录失败原因。

## 流程

1. 先识别当前画面。游戏处在「终端」菜单时，优先点击已定位的「索拉指南」入口。入口无法确认时，只有仍识别到终端才按 Esc，等回到大世界后再尝试 F2。识别到「Boss 图鉴」页签后才点击并确认切换。自动模式切到前台后会先等待画面稳定。日志分别记录画面分类、输入投递和页签确认结果。
2. 找到未完成目标后，重新确认同一行的入口按钮再点击。最多等待 10 秒确认传送或队伍界面，包含界面稳定时间。
   - 识别到队伍界面的「开始挑战」按钮 → 开始挑战；
   - 否则优先点击已识别的「快速旅行」文字所在的按钮区域，并处理识别到的确认框。等待传送与加载完成，上限 120 秒。确认世界及队伍画面恢复后才尝试按 F 进本并向战斗方向跑；
   - 原地图传送按钮持续存在时最多重新定位并重试一次。退出地图和跳过目标前再次验证当前画面。加载或未知画面未得到确认时保留失败状态。
3. 战斗循环（复用 `CombatRunner`）：
   - 大世界巢穴到达后，接近阶段最多 10 秒。有效 HUD 中连续看到敌人血条时直接出手，同时继续尝试锁敌。自动模式下，若后台持续有敌人但没有锁定结果，按现有窗口焦点规则尝试切到游戏前台；
   - 倒下时按自动复活设置处理已识别的复活按钮。连续三次倒下会停止并记录该聚落未完成；
   - 战斗结束后确认「吸收」提示；没有提示时先后退最多 2.5 秒，再前进最多 5 秒；
   - 模板和 OCR 没找到吸收提示时，让 YOLO 查看最多四个方向。发现声骸才进入最长 30 秒的靠近阶段；
   - 大世界巢穴每处最多重新传送一次寻找掉落；
   - 按 F 后确认左侧出现新的获取通知。已有的旧通知、提示暂时消失与画面丢失均不计入成功；
   - 等待掉落、找声骸或等待吸收回执时发现敌人，转回战斗。拾取后最多用 6 秒探测下一波，恢复到安静且可验证的游戏画面后才去核对图鉴进度；
   - 结束时显示有轮次未确认吸收的巢穴数。单次捕获模式在确认收到获取通知后结束。
4. 队伍挑战结束后先识别退出确认并核对大世界已恢复，再打开图鉴核对同一聚落。

## 与 ok-ww 的差异

| 项 | 参考 | 本项目 |
|---|---|---|
| 任务入口 | 框架管理图鉴键和窗口输入 | 独立 C# 窗口输入，使用 F2 并支持游戏内入口 |
| 目标定位 | 计数行推算点击点 | 用计数和同一行的入口按钮配对 |
| 同一目标跨页 | 页签和行槽位 | 聚落优先按名称去重 |
| 倒下恢复 | 复活后尝试重进，三次后跳过 | 验证复活后继续，三次仍失败时报告未完成 |
| 传送 | `_travel_to_nest_or_skip` 点击传送、处理确认，然后等待队伍画面最多 120 秒 | 逐帧区分原地图、确认和返回游戏，确认可恢复后才标记未到达并扫描其他巢穴 |
| 到达判定 | `in_team_and_world` 读取队友数字，成功后留出稳定时间 | 使用经验证的大世界或副本队伍画面，允许技能栏稍后出现 |
| 开战与换目标 | 中键主动找目标，确认锁敌后进行角色轮转 | 稳定识别到敌人时可先出手，继续尝试锁敌和角色轮转 |
| 一条龙出错后的恢复 | `DailyTask.run` 记录巢穴错误并恢复大世界，再继续其他项目 | 安全画面恢复后继续已选项目，最后保留失败项目名称 |
| 拾取兜底 | 走位 → YOLO 查看方向 → 重传送 | 大世界每个巢穴最多重传送一次 |
| 队伍挑战结束 | 单独发送退出并确认 | 验证退回大世界后再打开图鉴 |
| 捕获模式 | 战斗中尝试交互，确认获取通知后离开 | 战斗后的拾取流程用新获取通知确认后结束 |
| 普通刷取的推进条件 | 选择 `0/M` 的行，拾取后用战斗状态决定是否继续当前聚落 | 继续处理 `N<M` 的行，复核同一聚落的 `M/M` 后才推进 |

## 已知限制

1. 图鉴入口及副本识别根据实机截图回放校对。后台输入和整轮清场仍需实机验证。
2. 初次探测最多 10 秒，大世界另外有最多 10 秒的接近阶段。拾取后最多用 6 秒探测下一波。
3. 获取通知沿用原版检测区域以及数字 1、3。游戏内其他样式尚待验证。
