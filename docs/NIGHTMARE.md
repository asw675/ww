# 梦魇巢穴（Nightmare Nest）

任务按 F2 图鉴处理残象聚落和梦魇聚落。扫描及单次捕获按参考动作结果判断是否继续，实际完成及本次声骸获取仍根据独立证据核实，不把未核实结果记作成功。

## 刷取范围

| 选项 | 对应图鉴页签 |
|---|---|
| 声骸巢穴 | Boss 图鉴 → 残象聚落，逐屏扫描 |
| 梦魇净化 | Boss 图鉴 → 梦魇祓除，逐屏扫描带击败计数的聚落 |

两项可同时勾选。独立任务未勾选任一项时回退两项，先扫描残象聚落，再扫描梦魇祓除。

## 判定逻辑

- OCR 扫描图鉴列表区域（0.35,0.25–1,0.96），匹配 `N/M`；
- 清理全部时选择 `0 ≤ N < M` 且 `M ∈ {24,36,48,41}` 的目标，部分进度需要核对同一行的聚落名称和入口。单次捕获保持选择零进度的聚落；
- 按参考由计数框推算点击点 x=.9、y=框顶-.9×框高，确认其落在同一行可见的「前往」或「直接挑战」按钮内后使用；布局偏移时仅点已确认的按钮中心；
- 找不到候选时，确认相邻列表画面确实向下移动并保留重叠，再扫描新画面。找回已挑战的目标时，重新按名称与击败分母核对同一行。无名称的行额外核对当前滚动位置；
- 到达列表底部或识别到「特异梦魇」分组前最后一个常规聚落时，先处理屏内所有可用候选，再结束该分类。无法确认滚动推进时保留失败状态；
- 清理全部时重新核对同一聚落。`M/M` 计入完成，部分进度继续参与扫描，两次核对都未增加或无法读取时保留为未完成并扫描其他聚落。无法进入或传送未到达的目标会记录原因。

## 流程

1. 启动时先确认返回大世界（30 秒），不补打任务启动前的当前战斗。参考一条龙调度在已确认同一输入路由的图鉴/大世界时保留界面。打开 F2 图鉴，识别到「Boss 图鉴」页签后才点击并确认切换。自动模式切到前台后会先等待画面稳定。日志分别记录画面分类、输入投递和页签确认结果。
   - 使用分类标题或该分类专有的副标题定位侧栏入口。从顶部开始，每次向列表内容区滚动后复核新画面。回顶时可在识别到实际轨道后使用轨道点击兜底。
2. 找到未完成目标后，重新确认同一行的入口按钮再点击。最多等待 10 秒确认传送或队伍界面，包含界面稳定时间。
   - 识别到队伍界面的「开始挑战」按钮 → 开始挑战；
   - 否则优先点击已识别的「快速旅行」文字所在的按钮区域，并处理识别到的确认框。等待传送与加载完成，上限 120 秒。确认世界及队伍画面恢复后才尝试按 F 进本并向战斗方向跑；只要同一有效输入路由仍出现已识别交互，就继续处理 F 提示，不再限制三次；每次需在 40 秒内恢复队伍画面；
   - 原地图传送按钮持续存在时最多重新定位并重试一次。自动模式下同一客户端切换前后台时，重新采样并继续等待加载。退出地图和跳过目标前再次验证当前画面。加载或未知画面未得到确认时保留失败状态。
3. 战斗循环（复用 `CombatRunner`）：
   - 大世界巢穴到达后，接近阶段最多 10 秒。有效 HUD 中连续看到敌人血条时直接出手，同时继续尝试锁敌。自动模式下，若后台持续有敌人但没有锁定结果，按现有窗口焦点规则尝试切到游戏前台；
   - 倒下时按自动复活设置处理已识别的复活按钮。连续三次倒下会停止并记录该聚落未完成；
   - 战斗结束后确认「吸收」提示；没有提示时先后退最多 2.5 秒，再前进最多 5 秒；
   - 模板和 OCR 没找到吸收提示时，让 YOLO 查看最多四个方向。发现声骸才进入最长 30 秒的靠近阶段；
   - 大世界巢穴每波未成功投递拾取时，可按参考重新传送一次寻找掉落（重传仍需当前匹配同一行）；
   - 每次拾取以有效吸收提示按 F 一次，在同一路线观察新获取通知，最长 2.5 秒，并核对未打开错误领奖弹窗。旧通知、提示暂时消失与丢失画面均缺少新获取证据；
   - 普通模式等待掉落、找声骸或等待吸收回执时发现敌人，转回战斗。拾取后探测下一波，恢复到安静且可验证的游戏画面后才去核对图鉴进度；
   - 清理全部模式以完整扫描和同名聚落的击败计数核验清场，未核实的吸收回执会另外显示。单次捕获仍须读取本次新的获取回执。
4. 队伍挑战结束后先识别退出确认并核对大世界已恢复，再打开图鉴核对同一聚落。

## 与 ok-ww 的差异

| 项 | 参考 | 本项目 |
|---|---|---|
| 任务入口 | 框架管理图鉴键和窗口输入 | 独立 C# 窗口输入，使用 F2 并支持游戏内入口 |
| 目标定位 | 计数行推算点击点 | 用计数和同一行的入口按钮配对 |
| 同一目标跨页 | 页签、分母和行槽位 | 以聚落名称和分母重新定位。未识别名称时额外核对滚动位置和行槽位 |
| 倒下恢复 | 复活后尝试重进，三次后跳过 | 验证复活后继续，三次仍失败时报告未完成 |
| 传送 | `_travel_to_nest_or_skip` 点击传送、处理确认，然后等待队伍画面最多 120 秒 | 逐帧区分原地图、确认和返回游戏，传送失败缓存同一参考键，确认回到可操作界面才继续 |
| 到达判定 | `in_team_and_world` 读取队友数字，成功后留出稳定时间 | 使用经验证的大世界或副本队伍画面，允许技能栏稍后出现 |
| 开战与换目标 | 中键主动找目标，确认锁敌后进行角色轮转 | 稳定识别到敌人时可先出手，继续尝试锁敌和角色轮转 |
| 一条龙出错后的恢复 | `DailyTask.run` 记录巢穴错误并恢复大世界，再继续其他项目 | 当前项目在识别到可安全重试的界面后重试一次。仍未核实则停止并保留失败原因 |
| 拾取兜底 | 走位 → YOLO 查看方向 → 重传送 | 大世界每波最多重传送一次 |
| 队伍挑战结束 | 单独发送退出并确认 | 验证退回大世界后再打开图鉴 |
| 捕获模式 | 战斗中尝试交互，通知/拾取结果控制退出；不继续下一波 | 同样退出条件，另将真实新获取回执与动作结果分离 |
| 普通刷取的推进条件 | 选择 `0/M` 的行，拾取后用战斗状态决定是否继续当前聚落 | 可续打已核实身份的部分进度聚落；检查下一波和图鉴计数后判断清场 |

## 已知限制

1. 图鉴入口及副本识别根据实机截图回放校对。后台输入和整轮清场仍需实机验证。
2. 初次探测最多 10 秒，大世界另外有最多 10 秒的接近阶段。全清模式拾取后最多用 8 秒探测下一波。
3. 获取通知沿用原版检测区域以及数字 1、3。游戏内其他样式尚待验证。
