# 梦魇巢穴（Nightmare Nest）

对应 ok-ww `NightmareNestTask`：遍历 F2 图鉴里所有**未完成**的巢穴，传送、战斗、拾取声骸，失败的巢穴本轮跳过。

## 刷取范围

| 选项 | 对应图鉴页签 |
|---|---|
| 声骸巢穴 | Boss 图鉴 → 残响（canxiang，y=0.83），含滚动页 |
| 梦魇净化 | 梦魇（mengyan，y=0.86），含滚动页 |

两项可同时勾选；队列顺序：声骸巢穴 → 声骸巢穴滚动 → 梦魇净化 → 梦魇净化滚动。

## 判定逻辑

- OCR 扫描图鉴列表区域（0.35,0.25–1,0.96），匹配 `N/M`；
- 只处理 `N=0` 且 `M ∈ {24,36,48,41}` 的目标（未完成）；
- 目标点击点在列表右侧（0.9×宽，计数行上方 0.9 行高）；
- 缓存键 = 页签 + 分母 + 行槽位（行高 2% 取整），避免 OCR 抖动重复点同一目标；
- 已验证不可达/死亡 3 次的目标加入跳过集合。

## 流程

1. F2 打开图鉴 → 点击「Boss 图鉴」页签 → 选择分类页。
2. 找到未完成目标 → 点击 → 等待传送按钮（`gray_teleport`/`fast_travel_custom`/`remove_custom`）：
   - 出现队伍界面（`team_start_challenge`/`team_close`）→ 直接开始挑战；
   - 否则点传送并确认；传送后按 F 进本，再向战斗方向跑。
3. 战斗循环（复用 `CombatRunner`）：
   - 死亡：该目标死亡次数 +1，≥3 则跳过；
   - 战斗结束后拾取：先后退 2.5 秒、再前进 5 秒找 F；失败则 YOLO 找声骸 30 秒；
   - 仍失败且不是队伍界面：回大世界重新传送到当前巢穴再找一次；
   - 拾取后若又进入战斗则继续打。
4. 队伍界面进本的巢穴结束后退回大世界。

## 与 ok-ww 的差异

| 项 | 参考 | 本项目 |
|---|---|---|
| 主体流程 | 相同 | 相同（独立实现：队列 + `NestMath` + `WorldSession`） |
| OCR 计数 | PP-OCR | 同一 OCR，正则与分母集合一致 |
| 死亡跳过 | 3 次 | 相同 |
| 传送失败跳过 | 加入不可达集合 | 相同 |
| 拾取兜底 | walk → yolo → 重传送再找 | 相同 |
| 捕获模式 | `run_capture_mode` + 回声通知模板 | **未实现**（无 UI 配置，仅内部入口） |
| 回声通知判定 | 负片模板 | 未实现（仅捕获模式使用） |

## 已知限制

1. 未实机校准坐标与 OCR。
2. 战斗等待时间沿用 `CombatRunner` 的 2.5 秒脱战判定，参考在巢穴用 10 秒首战等待。
3. 捕获模式未移植（无用户入口）。
